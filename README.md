MovieFinder
MovieFinder is a movie search website built using HTML, CSS, and JavaScript.
Features:
* Search movies by actor or actress name
* View movie posters, ratings, release dates, and descriptions
* Explore trending and top-rated movies
* View actor profiles and movie details
* Save movies to a watchlist
* Dark and light mode support
* Responsive design for mobile and desktop
Technologies Used:
* HTML
* CSS
* JavaScript
* TMDB API
This project was built as a web development project


****NOTES****
## Notes
* Search results depend on the TMDB database.
* Some actors, directors, or regional film personalities may require their full name for accurate results.
* Availability of search results depends on TMDB data and popularity rankings.
